# 鲸屿 PC 网页端

独立的 Vue 3 + TypeScript + Vite 应用。与小程序共用数据契约、字段校验和 mock 业务规则，使用 SCSS 设计变量，没有新增 UI 库。

在仓库根目录执行：

```sh
npm install
npm run dev:backend
# 另开一个终端
npm run dev:pc
npm run type-check:pc
npm run build:pc
```

访问 http://127.0.0.1:5174，构建产物在 `dist/pc`。

当前完成首页：妆后图轮播、按场合筛作品、服务流程展开、演示预约（选择项目、化妆师、日期和时段，提交待付预约）、课堂概览、化妆品清单和门店信息。顶部导航跳转本页对应区块。

默认读取本地 Go 后端（8080 端口）的公开资料，浏览器通过 Vite 同源 `/api` 代理访问，不会混用浏览器 mock。`dev:backend` 使用内存模式，刷新网页不丢数据，重启后端会重置；持久化部署需要配置 MySQL，不使用此脚本。

需要独立演示时，把 `.env.example` 复制为 `.env.local`，设 `VITE_DATA_MODE=demo` 后重启前端，才会使用浏览器 mock 和演示预约。请求失败会明确提示，不会自动切换数据源。

手机与电脑连接同一 Wi-Fi 后，可用 Vite 输出的局域网地址访问，例如 `http://电脑局域网IP:5174/`（系统防火墙需要允许访问）；手机上的 `127.0.0.1` 指向手机自身。网页已针对 320px 起的窄屏调整导航、主视觉、卡片和弹窗。

网页登录尚未开发，本地后端模式下网页仅浏览公开内容；预约按钮引导使用微信小程序，不向受保护接口写入订单。预约管理、课程播放和店主工作台仍待开发。公开代理不转发微信身份、Authorization 和 cookie。

`build:pc` 的静态产物部署后需要服务器将 `/api` 反向代理到后端；Vite 的代理只在开发/预览运行。连接云托管时，可把 `PC_API_TARGET` 改为服务 HTTPS 地址，但受保护操作仍需要正式网页登录。

页面只通过 `@/api` 访问数据，公开请求层在 `pc/src/api/http.ts`，沿用小程序 Api 契约中的字段和方法。
